starten via:

npm run dev 
-> startet mit den Einstellungen welche in package.json unter "devDependencies" definiert sind

npm run build
-> Package wird gebuildet

npm run preview
-> Vorschau



=================================================================================================
Debuggen:

1. Definiton in launch.js
    {
        "request": "launch",
        "name": "Vite + React Debug",
        "type": "chrome",
        "url": "http://localhost:5173",
        "webRoot": "${workspaceFolder}/src",
        "sourceMaps": true
    }

2. npm run dev
-> Applikation starten

3. Debugger verbinden
-> Ctrl+Shift+D -> "Vite + React Debug" auswählen

4. Debuggen


=================================================================================================
Stoppen von laufenden Prozessen auf Ports:
netstat -ano | findstr :3000   
-> Auflistung der Services via netstat und anschliessend via Pipe suche (findstr) nach 3000

Kill Prozess:
taskkill /PID 15940 /F
-> via PID aus obigen Aufruf
